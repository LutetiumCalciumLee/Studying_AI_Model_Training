# Variational Autoencoder (VAE)
***
## What is a Variational Autoencoder (VAE)?
- A VAE (Variational Autoencoder) is a type of generative model that learns to encode data into a probabilistic latent space and then decode it back to the original data format.
- Unlike a standard Autoencoder (AE), which learns a direct mapping to a latent vector, a VAE learns the parameters of a probability distribution (typically a Gaussian) for the latent space.
- This probabilistic approach allows the model to generate new data by sampling points from the latent space and passing them through the decoder. The latent space is continuous and structured, enabling smooth interpolation between data points (e.g., morphing one face into another).

## Core Concepts of VAE
- **Encoder**: The encoder network takes input data (like an image) and outputs the parameters—mean ([`z_mean`]) and log variance ([`z_log_var`])—of a latent distribution.
- **Sampling Layer**: This layer uses the mean and log variance from the encoder to sample a latent vector [`z`]. It introduces randomness by adding a random epsilon scaled by the variance, which allows for the generation of diverse outputs.
- **Decoder**: The decoder network takes the sampled latent vector [`z`] and reconstructs the original input data. By feeding it new vectors sampled from the latent space, it can generate new data instances.
- **Loss Function**: The VAE is trained by minimizing a loss function composed of two parts :
    1.  **Reconstruction Loss**: Measures how accurately the decoded output matches the original input. This is often calculated using binary cross-entropy or mean squared error.
    2.  **Kullback-Leibler (KL) Divergence**: This is a regularization term that forces the learned latent distribution to be close to a standard normal distribution (mean of 0, variance of 1). It ensures the latent space is well-structured and prevents overfitting.

    - **Custom VAE Class**: A custom `VAE` model class is created by inheriting from `keras.Model`. This class defines a custom `train_step` to handle the combined reconstruction and KL divergence loss.
    - **Training**: The model is compiled with an optimizer (e.g., Adam) and trained on a dataset of images. During training, it learns to both reconstruct the input images and organize the latent space effectively.
    - **Generation**: After training, new images can be generated by passing randomly sampled vectors from the latent space to the decoder.
