# Studying_AI_Model_Training

## Learning Objectives
- Be able to develop AI web services using LLM, RAG, and Agent technologies.
- Be able to deploy the services that have been developed.

## Course Content
- Learn core technologies—LLM (Large Language Models), RAG (Retrieval-Augmented Generation), and AI Agents—through hands‑on practice in a Docker‑based environment.
- Strengthen practical skills step by step: build API servers with Flask/FastAPI, integrate a local LLM (Ollama) and ComfyUI, apply prompt engineering, design RAG systems, and implement AI Agents.
